MARINE REFERENCE SHOPIFY THEME
Version 2.0.0

This package is a native Shopify Online Store 2.0 theme. The Liquid templates are the primary source. The browser preview is rendered from those templates and is not a separate website converted into Shopify.

INSTALL
1. Open Online Store, Themes in Shopify admin.
2. Use Add theme or Import theme, then upload this ZIP.
3. Open Customize on the uploaded theme before publishing it.
4. Under Theme settings, Brand and ordering, select your boat history report product. Use your own product with its actual price and available variants. No product or variant ID from the reference store is included.
5. Set your brand name, logo, support email, contact page URL and delivery estimate.
6. Create a Contact page with handle contact and select its contact template. The theme has a native Shopify contact form.
7. Add your store policies in Shopify Settings. The footer reads the policies that exist in your store.
8. Review the theme on desktop and mobile, then publish when ready.

PRODUCT AND ORDER FLOW
The home page and the default product template contain the complete report landing page. On a product page, the form orders that product. On the home page, it uses the report product chosen in Theme settings.

The HIN entry accepts exactly 12 letters and numbers and changes letters to uppercase. It rejects spaces, symbols, short entries and overlong pasted values. A confirmation dialog shows the HIN, available report variants and the real Shopify price. The selected variant is added to the native Shopify cart with a HIN line item property. Checkout and payment are handled by Shopify.

A theme does not include access to a vessel database. Connect your existing report fulfilment workflow or an app that reads the order HIN and delivers the PDF. The theme never fabricates a vessel report or marks a vessel clear based on format validation.

CUSTOMIZATION
Use the theme editor to reorder sections and change headings, descriptions, images, statistics and FAQ blocks. Additional interface labels are in the default theme language content.

The customer review section is included but hidden until you add genuine review blocks. After adding reviews, enable Show testimonials navigation in Theme settings. No reviews or customer statistics from another business have been presented as your own.

The information strip allows optional source logos. Only add logos and source descriptions appropriate to the service you actually provide. Default statistics describe the form and report structure.

The country grid follows the reference layout and states that record availability varies. Adjust the countries section to the actual coverage of your reporting service.
